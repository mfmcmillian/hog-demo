# Heroes of Genesis

A Decentraland SDK7 collectible-hero game. Recruit heroes, party up, and walk the Roads. Everyone in the dungeon can win a collectible.

```
npm install
npm run start
```

Open the Decentraland preview, hold the phone portrait, and swear in on the start screen.

The Places title is **Heroes of Genesis**. The world name is `hogdemo.dcl.eth`.
